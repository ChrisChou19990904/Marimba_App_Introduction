1. MIDI是什麼？

MIDI（Musical Instrument Digital Interface）是一種數位音樂通訊協議，用來讓電子樂器、電腦、控制器之間互相「說話」。 它不直接產生聲音，而是告訴音源：

  • 哪個音符要彈
  • 音符的強弱（力度）
  • 持續時間
  • 音色、音量、表情控制

可以把MIDI想像成「數位樂譜」，而音源才是演奏出聲音的工具。

2. MIDI的原理

  • 事件(Event)：例如按下 C4 音符、力度 100 或放開 C4 音符。
  • 通訊方式：傳統MIDI使用5針DIN接口，每秒傳送31,250位元；現代則多用USB或藍牙。
  • 數據結構：MIDI訊息通常只需幾個bytes，例如： 
    0x90 0x3C 0x64  （Note On, C4, Velocity 100）
  • 解釋與播放：接收端（合成器或軟體音源）讀取MIDI指令 → 產生聲音。

3. MIDI vs 音頻 (WAV/MP3)

MIDI 音頻
內容 樂譜指令、控制訊息 聲音波形
檔案大小 非常小 通常很大
可調性 音色、速度、力度可自由修改 改動困難，需要再編輯音軌
依賴 需要音源（合成器或軟體） 自帶聲音

4. 對資工系和音樂系的重要性

資工系

  • 音樂軟體開發（DAW、合成器模擬器）
  • 演算法與資料結構（MIDI訊息序列、事件排序、同步）
  • 硬體通訊（USB、藍牙MIDI）

音樂系

  • 編曲與演奏：快速修改音符、力度、音色
  • 跨樂器協作：鋼琴鍵盤、鼓組、合成器同步演奏
  • 混音與製作：調整速度、音高、延音
核心公式：
MIDI ≈ 數位樂譜 + 控制訊號 → 音源合成 → 聲音

5. MIDI與應用程式的互動

以 Perfect Piano 為例：

  • 彈奏鍵盤 → 錄製MIDI事件（Note On/Off, 力度）
  • 儲存MIDI檔案 → 可命名管理
  • 上傳至 MuseScore → 自動生成樂譜（可能誤判拍子）
  • 上傳至 Marble Music → 生成動畫彈珠音效（動畫長度有限制）
鍵盤彈奏 → Perfect Piano錄製MIDI → 儲存檔案
        ├─> MuseScore: 轉成樂譜
        └─> Marble Music: 轉成彈珠動畫音效

6. MuseScore vs Marble Music 優缺點比較

功能/平台 MuseScore Marble Music
用途 樂譜製作、編輯、正式呈現 動畫視覺化、彈珠音效展示
優點
  • 自動把 MIDI 轉成樂譜
  • 可修改音符、節奏、速度、音色
  • 適合學術或正式樂譜呈現
  • 動畫直觀，視覺效果好
  • 原始 MIDI 速度保留，無拍子誤判
  • 操作簡單，上傳即生成動畫
缺點
  • 有時誤判拍子速度
  • 初學者需要手動調整量化與速度線
  • MIDI演奏速度不穩，樂譜可能不忠實
  • 動畫長度有限（約1分鐘）
  • 創作自由度受限，僅短片展示
  • 不適合正式樂譜編輯

7. MIDI與程式語言的關係

  • MIDI本身不是程式語言，而是一種協議。
  • 程式語言用於處理、解析、生成或控制MIDI檔案。
程式語言 用途 常用庫 / API
Python 生成、解析、分析MIDI檔案 mido, pretty_midi, music21
C / C++ 低延遲MIDI處理、硬體控制 RtMidi, JUCE
Java 跨平台音樂程式、樂譜軟體 javax.sound.midi
JavaScript 網頁MIDI應用、音樂可視化 Web MIDI API, Tone.js
Swift / Objective-C iOS / macOS 音樂App CoreMIDI, AudioKit
C# / .NET Windows 音樂App、遊戲 NAudio, Midi.Net

8. 實體電子琴與手機應用的差異

  • 實體電子琴可同時按下多個鍵 → MIDI能完整記錄和弦、主旋律+伴奏
  • 手機應用如 Perfect Piano 螢幕小 → 難以同時按下多個鍵，多音演奏受限
  • 網路上的多軌樂譜影片多來源於實體鍵盤錄製的MIDI檔

9. Marble Music自創作品上傳的條件

  • 必須有 MIDI 檔案
  • 創作者可以自己演奏錄製 MIDI（實體電子琴或數位鍵盤）
  • 或者使用別人提供的 MIDI 檔案
1️⃣ 自己演奏 → 錄製MIDI → 上傳Marble Music → 生成動畫
2️⃣ 使用別人MIDI檔 → 上傳Marble Music → 生成動畫
